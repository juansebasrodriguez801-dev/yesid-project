Quienes somos

Nosotros somos un grupo de 5 estudiantes de analisis y desarrollo de software encargados de diseñar una app y pagina web gracias a lo que estamos aprendiendo en el SENA.

Vision

Ser la plataforma líder en gestión de droguerías, integrando visualización 3D e inteligencia artificial para ofrecer un control de inventario moderno, seguro y eficiente, mejorando la experiencia de clientes y administradores.

Mision

Desarrollar un software intuitivo que permita a las droguerías administrar productos, ventas y stock en tiempo real, utilizando IA para predecir necesidades y modelos 3D para visualizar el inventario de manera dinámica y atractiva.

De que trata nuestro proyecto

Es una aplicación web que combina gestión tradicional de droguerías con tecnologías avanzadas: Visualización 3D de estantes y productos. IA predictiva para anticipar la demanda y optimizar pedidos. Automatización de facturación y reportes. Interfaz amigable para empleados y administradores.

Requisitos funcionales

Registro y administración de productos. Control de inventario con alertas de stock bajo.

Generación automática de facturas y reportes.

Visualización 3D de estanterías y bodegas.

Módulo de ventas y clientes.

Integración con proveedores para reposición automática.

IA para predicción de consumo y tendencias.


Requisitos no funcionales

Interfaz gráfica intuitiva y responsiva. Seguridad en el manejo de datos (roles y autenticación).

Compatibilidad multiplataforma (PC, tablet, móvil).

Rendimiento óptimo con bases de datos grandes.

Escalabilidad para múltiples sucursales.

Disponibilidad en la nube con sincronización en tiempo real.
